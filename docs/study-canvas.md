# 本机学习画布

本文定义原生学习画布的使用和存储接口。接入约束见[规格 0019](specs/0019-lecture-study-canvas.md)，渲染选择见[决策 0019](decisions/0016-native-lecture-study-canvas.md)。

## 学习界面

课程的「开始学习」及课次播放入口先打开传统播放器；播放器顶栏的「打开画布」进入学习画布，画布导航栏或操作栏菜单的「退出画布」回到播放器。画布只在用户主动切换后出现。课程视频使用现有播放器；视频模块内的入口以弹层打开大纲、文字稿、资料、笔记与助手。画布的导航、工具栏与笔盒布局见[画笔与橡皮](drawing-controls.md)。全屏沿用原生视频全屏，退出后回到当前画布。

画布跟随应用的深浅色。深色下纸张取主题的低层容器色并保留底色倾向，卡片高一级色调，以色阶而非阴影分层；深色墨迹提亮为同色相的浅色，荧光笔不变；PDF、图片等印刷页面保持原有浅底，其上的笔迹保留原色。工具栏、缩放与对话输入框是浮在画布上的玻璃层：半透明磨砂、提亮饱和度、顶部高光和外侧阴影，与页面边缘留出间距。设置的「液态玻璃」关闭后，或在高对比度下，这些层改为同形状的实色。玻璃层的分层思路参考 FlClash 的表面设计说明，仅借鉴设计原则，实现独立编写。画布工具避开系统状态栏、导航栏，全屏视频沿用沉浸模式。

视频、PDF 和图片统一作为卡片。手指从卡片正文或标题拖动可平移画布，双指可跨卡片缩放，原地长按后拖动才移动单张卡片；笔只有在框选整张卡片后才能移动它。鼠标保留标题拖动和右下角调整大小。完整手势、保护期和工具规则见[画笔与橡皮](drawing-controls.md)。钢笔与荧光笔可覆盖材料，笔迹记录压力；写在卡片上的笔迹随卡片移动和缩放。滚轮平移画布，⌘/Ctrl 加滚轮缩放。工具快捷键为 V 选择、H 移动、D 钢笔、E 橡皮；⌘/Ctrl 加 Z 撤销，增加 Shift 重做。

「导入」读取用户选择的 PDF、图片、UTF-8 TXT/Markdown 或本机视频。「课程资料」始终可见，按课次列出整门课程的本地文件，提供加载、空列表、错误与重试状态。新 PDF 保留源文件并建立按需翻页阅读模块；既有页面卡片保持原有布局。PDF 不提供页面文字拖选或原文选字弹窗，页面的真实文字与定位层继续保留，供显式加入的 AI 材料上下文使用；图像中的文字和手写笔迹不会自动识别。文字材料显示为可编辑的原文卡片。视频格式可选择不等于系统支持其中所有编码，解码错误由播放器显示。

PDF 模块标题栏的「在画布展开为一列」将各页按页码竖向铺在同一画布上。每页都是可写、可移动的页面卡片，标题标明页码；手形工具和触摸平移浏览，钢笔或触控笔直接批注。主文档保留为列顶部的标题栏，「收起整列」返回单页翻页模式，并将笔迹按页保存回主文档；再次展开可恢复各页标注。页面顺序渲染并逐页保存，已生成的页面固定在素材缓存中；中断后可点击「继续展开整列」补齐。对象的 `pdf_column` 记录所属主文档 ID，进入同一画布保存与课程同步范围。

导航栏的「课次素材」和课次视频卡片下的「字幕 · 资料 · 练习」打开素材架，把播放器侧栏的内容拆成可放进画布的素材：字幕按章节列出，点击一句跳到该时刻，单句或整章放入画布成为带视频来源的笔记卡片；资料按本课次和资料类别叠成一摞摞小文件，悬停时展开成扇面，单个文件拖出即导入画布，点开一摞查看全部；练习放入画布成为可作答的练习卡片，笔记按 Markdown 结构转成笔记卡片，对话入口打开侧栏中的独立会话。宽窗口中素材架在左侧，横向拖出列表；手机上素材架在底部，长按拖动。每项也可点 ＋ 放到视野中央，拖动时画布显示落点轮廓。素材架右上角仍可打开完整的播放器侧栏。

「问 AI」打开[多模态上下文与画布 Agent](multimodal-canvas.md)。本次资料可检查、移除，仅显式绑定的材料进入请求，课程视频不会自动加入；视觉区域需要主动勾选。AI 侧栏默认收起，选区可就地提问，回答可由用户主动留在画布；独立历史、草稿与引用行为见[多模态模块画布](multimodal-canvas.md)。模型只使用资料读取工具。画笔控制见[画笔与橡皮](drawing-controls.md)。

修改停止约一秒后自动保存，页眉显示结果。退出学习页和切换传统播放器会等待保存；保存失败时保留窗口内容并提供恢复文件导出。恢复 JSON 不包含素材二进制，素材保留在本机课程目录。应用退出前应等待「已保存到本机」。

同步文件夹中的整张画布按[课程同步契约](specs/0023-course-folder-sync.md)采用最后保存的版本，收到后自动刷新；被替换的版本保留在本机 `.sync-trash/`。不同设备的笔迹和卡片不做对象级合并。

## 存储与 API

每节课的 `study-canvas.json` 与 `study-assets/` 位于该课次目录，独立于 Markdown 笔记和原课件。`study-assets/<batch>/` 保存复制的源文件和 PDF 页面 PNG。导入转换在临时目录完成后原子发布整批文件；卡片移除和撤销不删除素材文件。程序不改动数据库 schema。

| 操作 | 接口 | 输入与结果 |
| --- | --- | --- |
| 读取 | `GET /api/lectures/{id}/study-canvas` | 返回文档；无文档时返回 revision 0 的初始视频画布 |
| 保存 | `PUT /api/lectures/{id}/study-canvas` | 完整文档及读取的 revision；返回递增后的 revision |
| 文件导入 | `POST /api/lectures/{id}/study-canvas/assets?name=...` | 原始文件字节；返回 `objects` 卡片数组 |
| 课件导入 | `POST /api/lectures/{id}/study-canvas/assets?path=...` | 当前课次内的原课件相对路径；返回同一对象结构 |

客户端读取 version 1/2/3，保存 version 3，包含 camera 的 x/y/z、layers、objects、strokes 和 connections。新字段定义见[多模态对象](multimodal-canvas.md)。不支持新版格式的旧应用拒绝 version 3，回退前须保留新版画布或恢复备份，不能用旧版覆盖新版文档。卡片记录 id/type/layer、x/y/w/h、title/text 及库内 path/source；笔迹记录 id/layer/anchor、tool/color/width 和 `[x,y,pressure]` 点列。导入素材引用只允许本课次 study-assets 内的常规文件；课程视频引用通过课程归属校验解析其他课次的本地视频；目录与文件符号链接均拒绝。所有接口使用现有 lookd 认证，Node 客户端同步声明接口；模型只返回回答与来源，完整画布文档由 Flutter 验证并保存。

文档上限为 32 MiB、32 图层、2000 卡片、30000 笔迹段、500000 点；坐标为有限值且绝对值不大于 1e9，缩放为 0.05–8。单文件导入上限为 300 MiB，文字为 800000 UTF-8 字节，分页 PDF 最多 5000 页，每页按需渲染；兼容旧整批导入的内部接口限 100 页且每页约 200 万像素，整批发布素材上限为 400 MiB。macOS PDF 转换由与 lookd 同目录的 `look-study-pdf` 执行；Linux/安卓使用[本地 Poppler 组件](study-workspace-build.md)，分页处理限时 45 秒，兼容旧整批导入限时两分钟。非法输入返回 400，超限返回 413，版本冲突返回 409，缺少课次返回 404；服务、文件系统或转换组件启动错误保留为失败，不覆盖旧文档。

源码直接沿用仓库的 Flutter、Go 和 Android 构建入口。PDF 与手写笔依赖、平台验收边界见[构建说明](study-workspace-build.md)。

## 模块画布版本

版本 3 读取版本 1/2 的画布，保留既有对象 ID、位置和笔迹。首次把已有画布保存为版本 3 前，后端保留原字节到 `study-canvas.pre-v3.json`；较旧应用不能直接读取新格式，回退需使用这份副本。新对话内容位于课次的 `study-conversations/`，与布局撤销分开保存，并进入既有资料备份范围；删除对话卡片保留其侧文件，以支持撤销恢复。原始课程文件不修改。三栏布局、分页文档、来源范围及对话协议见[多模态模块画布](multimodal-canvas.md)。
