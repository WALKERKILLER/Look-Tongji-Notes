# 多模态模块画布

本文定义原生画布的上下文、对话与工具行为。权限边界见[规格 0021](specs/0021-modular-canvas-conversations.md)，存储选择见[对话存储决策](decisions/0019-persistent-scoped-canvas-conversations.md)，使用步骤见[Demo 教程](tutorials/canvas-agent-demo.md)。

## 界面与资料

工具栏、导航、笔盒和纸张设置的布局与交互由[画笔与橡皮](drawing-controls.md)定义。视频的大纲与字幕从视频模块打开，传统播放器保留自己的侧栏。

课程资料按当前课程查询、按课次分组，具有加载、空结果、失败重试和不支持格式反馈。支持类型可以放入画布；大型课程视频引用原文件，通过受认证的 Range 端点播放。外部导入文件进入工作区素材目录，课程和原文件不改写。

## 上下文

每个对话拥有独立的手动参考资料。对象标题栏的加入对话按钮、引用条拖放、资料勾选与选区问 AI 是授权入口。当前视频和其他未绑定对象不自动读取。发送前上下文预览使用已保存画布 revision；绑定可分别保存文字范围、文档页码和视频时间段。

| 模态 | 实际输入 |
| --- | --- |
| PDF | 新导入使用分页模块，PDFKit / Poppler 按需提供单页 PNG、原文、UTF-16 范围和文字位置；支持页面拖选文字与视觉区域。旧 PDF 页面卡片保留。 |
| 文本、知识卡片 | 原始文字、结构块和用户作答；不会自动访问文字内的外部链接。 |
| 视频 | 优先读取绑定时间段的已有字幕。工具可提取最长 180 秒的本地音频交给现有 ASR 池，并缓存真实转录；开启视觉输入后可提取真实视频帧。缺少本地文件、ffmpeg、ASR 或视觉模型时明确降级，不读取完整远程视频。 |
| 手写、图片 | 本地裁剪实际选区后按需识图；选区文字/笔迹变化会阻止使用过期的视觉附件。不会每次落笔都调用模型。 |

PDF 页缓存保留有限数量的最近页面及正在保存的页面，渲染最长 45 秒、图像边长约 1400 像素。源 PDF 通过已验证的文件描述符交给解析器，翻页不复制整份源文件。页面笔迹带独立页码，翻页不会把同一对象其他页的标注显示或擦除。

## 对话与 Agent

对话在画布底部中央进行：输入框居中，对话按常规聊天顺序叠在其正上方，资料卡片仍留在四周可见。空画布只显示输入框，聚焦时给出示例问题。每个已绑定资料与输入框之间有一条细线；Agent 读取某份资料时这条线流向输入框、资料卡片显出光晕，进度文字写明正在读、听、转写或查看哪份资料；回答完成后被引用资料的线上走过一次光点。绘制或平移画布时对话淡出并让出输入。减少动态效果时线条静止。拖动卡片标题栏的加入按钮到输入框，或点击它，把资料加入当前对话。

每段对话在画布上是一个对话节点，显示轮数和最近的问题；点「继续」把它带到输入框上方，切换器可在对话之间切换或开始新对话。切走时进行中的回答继续完成。旧版 520×620 的对话卡片打开时缩成节点。对话节点通过 `conversation_id` 引用课次目录 `study-conversations/` 中独立的 revision 文件。记录草稿、用户问题、模型回答、来源范围指纹、失败或中断状态，以及回答来源。普通文本回答是正常结果。应用重启后未完成任务显示中断并可重试，不伪装为继续运行。

模型复用现有 ModelPipeline。历史只包含当前来源集合、范围和内容指纹完全一致的最近成功轮次；移除或改变来源后，不再提交其依赖历史或旧工具结果。工具清单如下：

| 工具 | 输入 | 输出 |
| --- | --- | --- |
| get_canvas_context | 无 | 已绑定资料、实际可用性与来源 |
| read_document_selection | source_id | 真实文字选区及锚点 |
| get_video_context | source_id | 已有或按需转录的真实时间段内容，或不可用原因 |
| inspect_canvas_region | source_id | 真实图像/视觉结果，或 unavailable |

运行状态的 `trace` 每步记录工具名、状态和所读资料的 `source_id`，画布据此显示正在读取的资料；它不改变工具权限。

引用前必须实际读取或观察对应来源。生成内容只显示在对话内，支持 Markdown、公式、代码和表格；模型不具备创建卡片、修改卡片、连线或自动定位工具。用户点击回答下的来源按钮才定位原资料。单次最多 20 次工具调用、12 轮模型响应、3 次视觉调用；工具任务最长 180 秒。片段解析支持取消，任务最长 150 秒并复用 ASR 的限流策略。

## 来源与恢复

Flutter 只保存回答及来源，忽略返回的画布操作。历史待确认操作不提供执行入口；既有卡片及手写仍可手动编辑、保存和撤销。对话历史、草稿及来源通过独立记录恢复。

来源包含工作区与对象 ID、文档 ID/页码、UTF-16 范围、归一化页面区域、笔迹 ID、视频时间和内容指纹。课程资料同时记录原课次和相对文件路径。点击引用可翻到原页、定位区域或跳转视频时间；无法定位时明确提示。画布格式和回退约定见[学习画布](study-canvas.md)。

## 验证边界

Go 验证受限引用、资料和对话隔离、原文件保留、CAS 与升级快照；PDFKit/Poppler 的真实解析测试区别于模型测试。Flutter 验证独立对话恢复、真实选区 PNG、每页笔迹、批次状态、画笔与手势回归。Node 协议 fixture 验证工具循环、资料移除后的历史隔离、视觉降级和取消，不能证明真实模型理解。真实推理需要已配置模型；平板帧率需要在实际设备上测量。
