# 学习画布画笔与橡皮

本文定义原生 Flutter 学习画布的笔盒、笔迹重放和已知边界。输入与存储基础见[学习画布](study-canvas.md)。

导航栏默认位于左上，提供返回、页面与材料索引、添加模块及浏览/手写切换；顶部中央的操作栏提供选择、平移、撤销、文字、文件、图层、套索、AI 与导出。笔盒默认贴底。各组有拖动把手，松手后吸附最近的边缘；横边横排、竖边竖排，过长内容可滚动，收起按钮固定显示。同一边相近位置已有另一组时交换位置；窄窗口把左上导航排到左侧，避开中央操作栏。纸张默认为白底横线，点击工具栏的「纸张背景」图标或「⋯ → 纸张背景」，可预览并即时切换空白、横线、点阵、方格，以及白色、米色、浅绿、浅灰底色。布局、收起状态及纸张样式保存在本机 `study.notein-layout.v2` 偏好，独立于课程文档和同步数据。

画布不显示顶部文字操作栏和左下角说明。保存状态通过云形按钮提示，传统播放器位于操作栏菜单，导出位于操作栏。macOS 画布通过已有 window_manager 插件隐藏窗口标题背景，保留系统窗口按钮与顶部拖动区域；离开画布后恢复普通标题栏。平板的系统状态栏和导航栏保持可用。

每支收藏笔独立保存笔型、颜色和宽度，最多 20 支。内置笔名随实际笔型更新；读取旧的错配内置名称时，以保存的笔型显示名称，自定义收藏名保留。首次点击选笔，笔尖升起；再次点击当前笔或长按，在该笔旁打开设置卡片。首次点击橡皮开始擦除，再次点击设置橡皮。常用颜色按双排色板显示，三档粗细在色板旁；从橡皮或选择工具点击颜色、宽度时恢复当前收藏笔。长按颜色进入调色板，长按粗细打开当前笔设置。套索选中时，属性区显示自由套索、矩形框选和区域问 AI。更多设置保留笔型、调色板、连续宽度及橡皮选项。

笔型包括圆珠笔、钢笔、铅笔、软笔与荧光笔，笔盒中的笔、橡皮与套索图形由 CustomPainter 独立绘制：钢笔为宽金属笔尖和深色笔杆，铅笔为木质削尖、石墨尖与黄色棱面笔杆，色带显示当前笔色。笔盒以 36 × 42 逻辑像素的原始截面为基准整体放大 15%，侧边宽度为 41.4、底部高度为 48.3 逻辑像素；拖动把手与底板紧贴，笔、色块和粗细选项采用紧凑间距。不透明度、压感响应和平滑参数具有实际渲染效果；预览与真实笔迹调用同一 paintInk。荧光笔支持圆头/平头并保持均匀宽度，钢笔、软笔和铅笔使用不同压力曲线，铅笔附加轻纹理；鼠标使用固定压力。

橡皮提供局部擦除、整笔擦除和圈选擦除，支持尺寸调节。局部/整笔模式显示与屏幕擦除半径一致的范围圈；圈选模式显示闭合轮廓。长笔迹拆成有界渲染段，各段通过 gesture ID 归为一次物理落笔，整笔擦除删除对应的全部分段；图层锁定和隐藏规则沿用文档模型。圈选擦除在抬笔后提交整笔删除。擦除可撤销，每段保存 brush 参数；version 1 无 brush 的旧笔迹沿用旧渲染。收藏、橡皮与停靠侧偏好在 SharedPreferences 中本机持久化。

压感橡皮默认开启，仅响应设备报告有效压力范围的手写笔。归一化压力达到阈值且笔尖始终留在落笔点的 6 个逻辑像素范围内，连续重压 380 毫秒时，临时使用局部橡皮；抬笔恢复原笔型。默认阈值为 0.8，设置支持 0.55–0.98，数值越低越灵敏。一旦离开落笔点的 6 个逻辑像素范围，这一笔不再触发压感橡皮，即使回到起点；鼠标、手指和不报告有效范围的设备不触发。停留前已写的路径与擦除共用一次撤销记录，触发尾点不保存为额外墨点。支持系统报告的 invertedStylus 擦除；标准侧键及预测行为见下文「原生手写笔输入」。

每支收藏笔的「一笔成形」默认开启，可在相邻设置卡片或更多画笔设置中独立关闭。用手写笔或鼠标画出图形后，保持落笔并在 6 个屏幕逻辑像素内停留 700 毫秒，符合几何条件的笔迹会预览为直线、圆、椭圆、三角形、矩形或凸四边形。接近水平或垂直的直线吸附对应方向。成形后继续按住并移动，可调整直线终点，或围绕封闭图形中心旋转、等比缩放。识别允许较小闭合缺口和手绘边缘抖动；快速抬笔、很小的笔迹、较大缺口的开放曲线、多圈和不符合条件的涂写保持手绘；手指沿用平移手势。识别在本机完成，不调用模型服务。

原地落笔的重压停留用于压感橡皮；画出路径后的停留用于一笔成形，与末端压力大小无关。已成形预览保持调整模式直至抬笔。取消输入或离开页面不会把预览保存为新笔迹。抬笔后图形沿用普通笔迹格式，保留当前笔型、色彩、宽度、图层和文档页来源，按既有规则保存和同步。当前编辑会话内第一次撤销恢复成形前的手绘笔迹，再次撤销移除该次落笔；识别不会改写已保存的其他笔迹。

箭头在空白处拖动平移画布，在对象标题/角点处移动或缩放对象。套索为独立工具，可选自由曲线或矩形。套索选中同次落笔的全部分段，包含稀疏线段穿过选区的情况；圈住整张卡片才把它纳入对象移动，圈在文档内部仅选择笔迹或视觉区域。选区旁提供复制、画布内粘贴、副本、改色、粗细、删除和问 AI；拖动选区移动，拖右下角缩放。编辑保留原笔迹 ID、来源与压力，副本获得新 ID；锁定图层不修改。问 AI 每次最多引用 500 个笔迹分段，超出时提示缩小选区。复制缓冲区仅在当前打开的学习页有效，实际编辑结果正常保存与撤销。

两指缩放和平移使用[保留世界坐标布局](decisions/0018-retain-world-layout-during-canvas-gestures.md)，在手势过程中更新变换，越过缓存边界或停稳后重新筛选材料。视频保持实时组件；网格、尾端笔迹、套索和橡皮提示独立重绘。控制条先拦截输入，取消事件不会把未完成笔迹保存下来。

这些是独立实现的绘制工具，笔触不会与 Notein 的专有渲染完全相同。不提供激光笔、胶带或 Notein 的完整设置兼容；一笔成形不识别多笔组合或任意复杂图形。平板和手写设备的真实压感、掌触抑制效果与帧率需要设备测试；Mac 鼠标测试不等同于华为平板验收。

## 交互核验与参考边界

用户提供的 46 秒录屏展示了侧边工具条、快速切笔、自由套索及靠近选区的菜单。定向 REA/JADX 检查同一官方 APK 的 `PenBox` 与 `LassoParams`：笔盒有位置/展开状态、笔宽/颜色事件；`setPositionWithAnim` 使用 200 毫秒位置动画；`getContextMenuPos` 返回选区上边中心点。对应证据为 `ev_36272801481a5d95ccb70c493070fa3fde41869d0876906697345893b68b1b42`、`ev_5a93de7c5b6f5a31f25a5fdce2d62d5337b89397d38267353b63754ad9d28ebe`、`ev_bd26a499fa4e7eecd74613ae3870e89800069700cd58bbdfd01872a299ceaa98`。这些静态证据仅用于理解交互，不代表取得原始工程，也不证明设备帧率。

华为[压感橡皮帮助](https://consumer.huawei.com/cn/support/content/zh-cn15936802/)用于核对重压停留、抬笔返回书写的交互语义。华为公开的 Android [Pencil Engine](https://developer.huawei.com/consumer/cn/hms/huawei-pencilengine/)提供手写套件和笔迹预测能力，但它不等于华为笔记的完整开源工程；Android 通过官方 Maven 依赖接入其预测 API，未复制其实现代码。

`app/test/study_handwriting_test.dart` 验证橡皮圈真实像素、压感停留/恢复/取消、不支持压力时的降级、套索编辑与撤销、保存恢复、文档来源及缩放时布局保留。`study_canvas_ui_test.dart` 继续覆盖可编辑卡片、真实选区、视觉裁剪和来源跳转。测试手势与栅格结果不能替代 M-Pencil 压力标定、MatePad 帧时间或真实视频播放实测。

贴边交互的 Flutter 实现与 Notein 无共享代码或图片。静态 APK 证据不证明全部运行时交互。实机对照使用平板已安装的 Notein v2.1.22.0（versionCode 353），在独立空白测试文档验证首次点选笔后笔尖升起、双排颜色与三档粗细、再次点击当前笔后弹出相邻设置卡片，以及把笔盒从底部拖到右侧。UI 采用这些可观察交互，未复制专有代码或图像；本项目的窄屏重排和占位交换是独立规则。`study_canvas_ui_test.dart` 通过实际工具栏拖动验证停靠持久化和画布内容不变，并验证选笔、独立宽度、再次点击设置及橡皮后的快速颜色切换。

一笔成形入口参考同一平板 Notein 钢笔设置中实际显示的「一笔成形」开关。识别、阈值、图形调整和撤销规则由本项目独立实现，未移植 APK 算法，也不声明与其识别范围相同。`study_shape_test.dart` 覆盖带噪声几何拟合、缩放、拒绝涂写、停笔和快速抬笔、取消、调整、偏好持久化及成形后撤销恢复；压感橡皮回归由 `study_handwriting_test.dart` 继续覆盖。

## 原生手写笔输入

在画笔设置中点「手写笔与预测」可开关 Android 笔迹预测、查看引擎状态和当前页面接受的预测帧数；统计在打开弹窗时读取，重新打开可刷新。优先使用设备上的华为 Pencil Engine，缺失、异常或无结果时使用 AndroidX Input。预测仅画在当前笔尖尾端，48 毫秒后过期，真实报点到达、抬笔、取消和形状识别时清除；保存、撤销与同步只使用真实笔迹。数据边界及官方来源见[原生预测决策](decisions/0023-native-stylus-preview.md)。

支持标准侧键的笔在悬空按键时切换当前笔与橡皮；按住侧键落笔则只在这一笔内临时擦除，抬笔后仍使用原笔。笔尖倒置擦除继续有效。书写途中收到切换事件不会改变当前笔迹的工具。未接入 M-Pencil 专用双击、轻捏协议；Android 标准按钮支持不能证明这些厂商手势可用。

一笔成形还支持凸五边形、凸六边形和连续画出的单向箭头。箭头画法为笔杆起点 → 箭头尖 → 一侧翼 → 返回箭头尖 → 另一侧翼，最后停住约 0.7 秒。形状仍以普通笔迹保存，撤销一次还原自由手绘，第二次撤销移除该笔。复杂涂写、开放圆弧和多笔组合保持原样。

`study_stylus_test.dart` 通过实际 Flutter 平台通道和像素检查验证预览出现、过期、拒绝旧帧和保存时排除预测点，并验证侧键临时橡皮恢复。SDK 与物理笔的协作仍以设备实测为准；自动注入的 stylus MotionEvent 不等同于真实 M-Pencil 操作。
