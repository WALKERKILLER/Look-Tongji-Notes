# 模块画布 Demo

本教程使用自己选定的真实学习资料。协议测试中的回答不属于模型推理证据。

1. 在设置中准备 AI 运行时和模型服务。手写、扫描件和视频画面需要视觉模型；新 PDF 导入在 Android 需要诊断页的 PDF 组件。视频短片段解析需要 ffmpeg 和可用的转录服务。未配置这些组件时，既有画布和资料仍可使用。
2. 点击课程「学习」。确认顶部固定导航、中央细工具栏和底部笔盒；测试笔盒与 AI 入口的拖动贴边。打开「课程资料」，确认按课次列出本课程文件，再放入一个 PDF。新 PDF 使用单个翻页模块。
3. 通过 PDF 模块标题栏把当前页加入 AI 对话。引用条应只有显式加入的材料；点击查看资料内容核对该页提取的原文。请求「解释这页内容，并注明来源」。点击回答下的来源，确认返回原页。没有文字层的扫描件应使用区域选择并允许视觉输入。
4. 暂停课程视频，通过视频标题栏加入同一对话，在引用条调整时间范围；保留 PDF 当前页引用。请求「结合这段讲解解释实验要求，保留两个来源」。优先使用已有字幕；缺少字幕时工具只能处理已选的本地短片段，缺少本地录像或服务应显示明确缺口。
5. 用笔书写或圈出局部区域，通过选区「问 AI」在旁边的短输入框提问，需要看笔迹时勾选「附选区图」。确认实际选区进入请求，模型回答显示在右侧对话栏中。文字模型不能看图时应说明限制，不能编造识别结果。
6. 请求「整理成对比表格」或「生成三道练习」，确认全部内容显示在同一对话中。继续要求简化解释；画布不自动新增知识卡片或连线，既有资料不被修改。点击回答的「留在画布」，确认出现可编辑的文字卡片，撤销后原回答仍在对话中。
7. 再新建一个 AI 对话，绑定不同资料并输入草稿。关闭并重开课程，打开右侧 AI 入口，通过切换器确认两个对话、草稿、历史及来源各自恢复，原资料位置保持。删除一个引用后继续提问，模型不能通过旧工具结果或依赖该来源的历史继续使用它。
8. 在 MatePad 使用相同资料，比较长笔迹、擦除和双指缩放，以及 AI 工作时的书写。性能结论须以该设备实测为准。安装更新保持现有应用 ID 和签名，不先卸载；跨设备资料迁移仍使用设置中的备份导出/恢复。
