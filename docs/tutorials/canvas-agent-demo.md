# 模块画布 Demo

本教程使用自己选定的真实学习资料。协议测试中的回答不属于模型推理证据。

1. 在设置中准备 AI 运行时和模型服务。手写、扫描件和视频画面需要视觉模型；新 PDF 导入在 Android 需要诊断页的 PDF 组件。视频短片段解析需要 ffmpeg 和可用的转录服务。未配置这些组件时，既有画布和资料仍可使用。
2. 点击课程「学习」。确认顶部工具栏、底部笔盒和左侧模块栏；测试收起和换边。打开「课程资料」，确认按课次列出本课程文件，再放入一个 PDF。新 PDF 使用单个翻页模块。
3. 在 PDF 模块中点击「选择文字」，拖选真实文字后问 AI。对话模块的引用条应只有该选区；点击查看资料内容核对实际摘录。请求「解释所选内容，并注明来源」。点击回答下的来源，确认返回原页。没有文字层的扫描件应使用区域选择并允许视觉输入。
4. 暂停课程视频，通过视频标题栏加入同一对话，在引用条调整时间范围；保留 PDF 选区。请求「结合这段讲解解释实验要求，保留两个来源」。优先使用已有字幕；缺少字幕时工具只能处理已选的本地短片段，缺少本地录像或服务应显示明确缺口。
5. 用笔书写或圈出局部区域，通过选区问 AI 并勾选视觉输入。确认实际选区进入请求，模型回答保留在对话框中。文字模型不能看图时应说明限制，不能编造识别结果。
6. 请求「整理成对比表格」或「生成三道练习」，确认全部内容显示在同一对话中。继续要求简化解释；画布不新增知识卡片或连线，既有资料不被修改。
7. 再新建一个 AI 对话，绑定不同资料并输入草稿。关闭并重开课程，确认两个对话、草稿、历史、卡片位置和来源各自恢复。删除一个引用后继续提问，模型不能通过旧工具结果或依赖该来源的历史继续使用它。
8. 在 MatePad 使用相同资料，比较长笔迹、擦除和双指缩放，以及 AI 工作时的书写。性能结论须以该设备实测为准。安装更新保持现有应用 ID 和签名，不先卸载；跨设备资料迁移仍使用设置中的备份导出/恢复。
