# 接入课程同步文件夹

本教程将一门已有课程接入 Syncthing 管理的同步文件夹。同步目录使用 Look Studio 专用交换格式，各端自动导入自己的工作库；不要把 SQLite 数据库和私有设置放进 Syncthing。

## 1. 准备同步目录

在每台设备的 Syncthing 中接收同一个共享文件夹，等待 LookStudioSync/library.json、devices 和 objects 下载完成。NAS 保存常在线副本，设备离线时仍可阅读已导入的课程。不要另外新建一个空的 LookStudioSync 来代替已有目录。

如果移动端只需要课程，可以在接收共享文件夹前，为新的本机接收目录创建 `.stignore`，按顺序写入下面两行。文件夹 ID 保持与其他端一致；Syncthing 接收目录是 LookStudioSync 的父目录，Look Studio 选择的则是其中的 LookStudioSync 子目录。

```text
!/LookStudioSync
*
```

该规则只接收根目录下的 LookStudioSync；不要在已有完整共享目录副本上直接套用，以免影响其他用途。忽略规则不在设备间同步，其他端需要单独配置。Syncthing 的全局统计可能包含被忽略的文件，实际占用以本机文件夹为准。规则依据见 [Syncthing 官方忽略文档](https://docs.syncthing.net/users/ignoring.html)。

## 2. 连接 Look Studio

安装同版本测试包，打开“设置 → 数据与同步 → Syncthing / NAS 同步资料库”。没有学校登录的新设备可以先点击登录页底部“本地课程与同步（无需学校登录）”。

Mac 或 Windows 使用系统目录选择器选中 shared-folder/LookStudioSync。安卓使用系统文件夹选择器选中 Syncthing 已接收的同一目录，并授予该文件夹读写权限；不要选择应用私有目录、下载根目录或整个手机存储。

只勾选“操作系统期末速成”，开启“包含视频和音频”和“自动检查与发布”，点击“预览并接入”，核对预览后接入。首轮需要等待所有对象完整到达并校验，列表中应出现六节课和课件。传输未完成时保留本地内容，稍后自动重试。

## 3. 保存和接收

笔记或画布显示“已保存到本机”表示本地保存完成。同步设置中的“已写入同步文件夹”表示本机已发布；其他设备是否收到，以各端 Syncthing 和 Look Studio 接收状态为准。传输需要时间，文件夹同步不保证即时协作。

前台应用保存后约两秒触发发布，约五秒检查一次目录；安卓回到前台会检查。系统暂停后台应用时，重新打开后恢复同步。对话和练习按记录标识合并；同一笔记的独立修改保留冲突副本。整张画布按最后保存的版本自动更新，被替换内容保留在本机 `.sync-trash/`；本机正在写的内容完成保存后成为新版本。不同设备的笔迹和卡片不会分别合并。

保存后两端没有更新时，先检查 Syncthing 是否连接、文件夹是否“最新”，再检查 Look Studio 的接收状态。跨网络中继与断网后的重新发现可能需要数分钟；“已写入同步文件夹”不能证明其他设备已收到。使用时保持 Syncthing 运行，设备省电策略暂停它时需要重新打开。

## 4. 处理冲突和权限

在同步设置中点击“查看冲突”，检查副本后选择“保留当前版”或“使用此副本”。恢复会保留被替换内容，确认处理不会删除恢复副本。不要手工删除同步对象或修改设备清单。

安卓权限失效时重新选择原文件夹。遇到格式版本不兼容时先升级所有客户端；文件校验失败时等 Syncthing 重传，避免直接覆盖工作库。

## 5. 回退

停用自动同步并退出测试应用后，可以重新安装升级前测试包；先备份应用、工作库和 library.db；备份位置由你自行选择。请保留现有工作库，发生问题先备份再恢复数据库。同步目录不包含学校凭证、模型密钥和数据库，不能代替完整本地备份。

技术边界见[课程文件夹同步规格](../specs/0023-course-folder-sync.md)。
