## Contract

Each device keeps its working library, SQLite index, credentials and runtime private. A folder transport publishes only explicitly selected course trees, course-scoped assistant history and portable personal state. A versioned marker identifies the portable library. Immutable SHA-256 objects and separate device manifests prevent a file transfer racing its manifest from installing incorrect bytes. A missing or corrupt object leaves the local copy intact and is retried. Unknown versions are rejected before import. Vector clocks detect edits made independently. For `study-canvas.json`, the latest saved whole document is selected automatically: causally newer saves win, concurrent saves compare file modification time, and equal times use a stable hash tie-break. Losing canvases remain recoverable under `.sync-trash`, without blocking conflict prompts. Other conflicting content retains the existing manual review flow. Deletions retain a recoverable copy. Device clocks must be accurate for concurrent offline save ordering.

Before applying a generation, course directory mappings must target a nonexistent directory or a directory whose `course.json` has the same course ID. Global quiz destinations and assistant session IDs retain their existing course ownership, including deletions; unclassified chats cannot be claimed by incoming course metadata. Assistant export matches the session header ID, not a substring of its filename, and scans headers once per export round rather than once per selected course. A same-course rename is accepted when the same generation contains the old path’s tombstone and exactly one live replacement. `sessions-meta.json` is authoritative for existing local session ownership; per-course export caches cannot undo local reassignment and empty selected-course exports are removed. Releasing a locally reassigned session from its old course preserves the global file. Malformed global quiz/session files outside the selected or previously tracked scope are left untouched; a malformed tracked file stops publication with its path in the error. All destination ownership checks complete before the first working-file replacement.

Each folder object is limited to 4 GiB, and a receive generation may stage at most 8 GiB of unique objects, including objects needed for conflicting versions. This is a staging limit only: installed working files, `.sync-conflicts` and `.sync-trash` copies consume additional space and can make peak disk use exceed 8 GiB. Negative sizes, invalid hashes and inconsistent sizes for the same hash are rejected before opening objects. A record merge reads at most 32 MiB across all versions; larger histories retain file-level conflict handling. Exceeding a receive limit leaves working files unchanged and reports an error; select fewer courses or disable media to reduce a generation. Local scan and hashing errors, including an unavailable configured root, stop publication; unreadable files are not published as deletions. These bounds limit temporary work, not total library size, and do not guarantee that a device has enough free disk space. Metadata documents are bounded to 32 MiB.

The folder bridge checks every five seconds and coalesces local saves for two seconds. Received changes refresh relevant screens. The open canvas independently checks its current saved document every five seconds while visible and when returning to the foreground, so a lost push notification cannot leave it stale. A clean canvas adopts the received document automatically. An unfinished local stroke or pending local edit completes its automatic save against the current revision, becoming the newer whole document; revision races retry at most twice. Legacy crash drafts remain recoverable. Replaced saved canvases retain recovery copies. This is whole-document replacement, so a later saved layout can supersede earlier handwriting; objects and strokes are not merged. Status distinguishes local publication from cross-device delivery. Android uses a persisted system directory grant and a bounded native HTTP storage bridge; arbitrary host paths are not exposed. WebDAV retains its existing behavior and cannot run concurrently with folder sync for the same local configuration.
