# 无 PPT 截图课次的画面抽帧

Artifact-Version: 1
Status: Draft

由 agent 起草，待用户确认后改为 Approved 并编号；确认前不实施。

## Intent
部分课次没有系统提供的 PPT 截图（本地课程、复旦课程，以及截图缺失的同济课次），助手只能靠文字稿理解课程，公式、图表、板书和术语容易出错。目标是让助手在这类课次上按需「看」录像：助手只决定看哪些时刻、为什么看；抽帧、去重和是否为课件的判断由系统完成，通过检验的画面才交给助手作为理解材料。

范围：课程助手与常驻助手的工具调用、lookd 抽帧接口、画面缓存。非目标：自动为整节课抽帧；替代已有 PPT 截图（有关键截图的课次继续用 view_slides）；画布模型的工具集（规格 0021 维持只读工具，本规格不向其开放）；视频内容的 OCR 全文索引。

约束：登录会话、录像地址与请求头只留在 lookd 内，不返回给 agent 或前端，也不写入日志；画面只在本机缓存，只在工具结果中发给已配置的模型服务（与 view_slides 相同）；课件判断不由对话中的助手自评。

## Contract
**工具 `sample_frames`（agent）**
- 参数：`lecture_id`；`moments` 1–6 项，每项 `{ at: "MM:SS", why: "key" | "doubt", note? }`。`key` 指重要讲解时刻，`doubt` 指文字稿存疑处；`note` 不超过 80 字，只用于结果标注。
- 仅当课次没有关键 PPT 截图时出现在助手的工具清单中（lecture_info 的 `slide_times` 为空）；有截图时调用返回错误并提示改用 view_slides。
- 返回：通过检验的画面（模型可看图时直接给图，否则给视觉模型的转写，与 view_slides 同一管线与缓存）、每张的实际时间 `[mm:ss]` 与可嵌入笔记的 Markdown；被拒画面只给计数与原因类别（重复、非课件、黑屏或模糊、读取失败），不给图。
- 每次调用最多 6 个时刻、返回最多 6 张画面；同一课次每天最多抽取 60 次时刻，超出返回明确错误。

**抽帧（lookd，受认证 API）**
- `POST /api/lectures/{id}/frames`，请求 `{ times_ms: [...], window_ms }`（`window_ms` 默认 8000，上限 20000），返回任务 id；`GET .../frames/{task}` 查询，`DELETE` 取消。同一 lookd 最多 2 个抽帧任务并行，每个任务 120 秒超时。
- 视频来源优先使用本机已下载的录像，否则由 lookd 用现有会话直接读取该课次的在线视频流。两者都不可用时返回「这节课没有可读取的录像」。
- 每个时刻在 `[t − window/2, t + window/2]` 内取 3 个候选帧，缩放到宽 960 像素以内；选择最清晰且与相邻候选差异最小（画面稳定）的一帧。
- 系统检验，依次进行：
  1. 黑屏、过曝或模糊（亮度与边缘强度阈值）→ `blank`；
  2. 与本次及该课次已接受画面的感知哈希（64 位 dHash）汉明距离 ≤ 6 → `duplicate`，并给出 `duplicate_of`；
  3. 课件判断：由 agent host 用设置中的视觉模型（未设置时用可看图的对话模型）以固定提示词逐张分类，输出「课件 / 板书 / 屏幕演示 / 其他」，只有前三类 → `accepted`，其余 → `not_courseware`。分类结果按图片哈希缓存，费用记入用量账本（用途 `frames`）。两种模型都没有时，只做第 1、2 步，结果标为 `unchecked`，工具结果中说明未做课件判断。
- 结果：`{ state, frames: [{ t_ms, verdict, duplicate_of?, path }] }`；`path` 为 `/api/lectures/{id}/frames/{name}` 形式的库内图片地址。

**缓存与界面**
- 已接受的画面保存在该课次目录 `frames/`，索引为 `frames.json`（`look-studio/frames@1`：时间、哈希、判定、来源时刻与原因），跟随课程目录同步；被拒候选不落盘。重新抽取同一时刻命中缓存，不重复读取视频。
- 播放器「资料」页与画布「课次素材」在有画面时显示「录像画面」分组，可删除单张或全部；删除不影响录像与文字稿。

**错误**
- 未安装 ffmpeg、会话过期、录像读取失败、超时、取消均返回中文原因，以「无法」开头；部分时刻失败时其余结果照常返回并计数。

## Plan
lookd：新增 frames 模块（ffmpeg 抽候选帧、清晰度与稳定度评分、dHash、索引读写），server 增加上述路由，复用 study_media 的任务表与在线流读取（会话请求头只在 lookd 内拼装）。agent：tools.mjs 增加 sample_frames 并在 lecture_info 无截图时启用；vision.mjs 增加固定分类提示词与缓存。Flutter：资料页与课次素材读取 `frames.json`。Dart 与 Node 客户端一起更新。

## Verification
- Go：用 ffmpeg lavfi 合成录像（纯色黑屏段、相同画面段、带文字图形段、摄像头式噪声段），验证黑屏拒绝、重复判定与 `duplicate_of`、候选选择、窗口与数量上限、取消与超时、缓存命中、会话头不出现在响应与日志中。
- Node：桩接 lookd 与模型，验证工具仅在无截图课次出现、参数上限、分类缓存与用量记录、`unchecked` 降级说明、被拒画面不返回图片。
- Flutter：有画面与无画面两种课次的资料页与课次素材，删除单张与全部。
- 端到端：一节无截图的本地课程，助手对 2 个疑点时刻调用后，笔记中嵌入的画面与时间正确。
