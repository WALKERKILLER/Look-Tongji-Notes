# 分类资料库与文字稿旁注审校

Artifact-Version: 1
Status: Implemented

用户于 2026-10-27 确认按此规格实施。

## Intent
将本机课程文件与笔记统一编目，按课程、用途类别和文件类型查找。AI 结合该节文字稿、课程信息及可用课堂材料检查疑似识别错误，用旁注表达推测，保留原始转写。

## Contract
- 资料库同时展示课程目录内的原始资料和笔记；支持课程、类别、文件类型组合筛选以及名称检索。类别包括课件、作业、Lab、文字稿、录像、课堂截图、笔记、参考资料和其他。分类依据文件名与目录，不将 PDF 等格式当作用途类别。
- 文件不搬移、不改名、不删除；笔记打开阅读器，文件使用现有库内文件打开机制。忽略元数据、数据库、临时文件、解析缓存和符号链接；不会扫描课程库以外的目录。分类来源在界面说明，无法判断的资料归为其他。
- 文字稿增加「AI 审校」入口，用户启动后自动分段检查完整课次；使用应用已配置的模型服务。启动前说明发送的文字稿与课堂材料摘要、可能产生的模型费用；不要求用户在聊天中提供密钥。
- 审校使用原文邻近上下文、课程与课次信息、可用的该节 OCR/课件文字。材料中的指令视为数据。没有依据时保留原文，不纠正口语风格，不补写无法辨认的内容。
- 疑点旁插入颜色与字体有区别的「（AI 推测：候选词）」；可以查看理由和依据、隐藏全部旁注、忽略单条建议。原文、时间戳、SRT、全文检索原始数据不变。
- 建议保存为该课次独立 JSON 旁注，包含原文指纹、片段编号、原词、候选词、理由和依据。服务端验证原词确实在对应片段内，拒绝错位、重叠、超长和过量建议。转写变化后旁注标为过期，不贴到新版原文。
- 同一课次只运行一个审校任务；可查询进度、取消、失败后重试；原文、模型和分段数量相同的未完成任务从已保存进度继续。未通过原词与逐字引用校验的候选建议被过滤并计数；部分结果明确标为未完成；重启保留已保存旁注，运行状态不假装完成。模型密钥沿用现有后端配置，不返回前端。
- 不增加聊天工具写权限，不改变笔记覆盖、文字稿覆盖率或常驻助手操作卡片的现有保护。

## Plan
在 library 模块提供文件编目与旁注文件持久化，server 提供受认证 API；agent host 复用现有模型管线完成分段审校与进度管理；Flutter 资料库与文字稿侧栏消费这些接口。API 的 Dart 与 Node 客户端一起更新。

## Verification
验证课程与类型/类别组合筛选、中文与 Lab 文件名分类、无目录越界或重复元数据；验证完整分段覆盖、模型输出校验、原文指纹冲突、取消与重试、旁注重启恢复。确认原 SRT/Markdown 和原片段逐字未变，明暗主题旁注可辨识，未配置模型时显示设置提示。
