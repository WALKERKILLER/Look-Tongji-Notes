# 新建本地课程

本文说明如何把本机视频作为学校课程之外的独立课程学习。导入接口、文件边界与恢复约定见[本地课程规格](specs/0022-local-courses.md)。

1. 打开「课程」，点击右上角的加号「新建本地课程」。
2. 填写课程名称，可选填写讲师或来源；点击「选择视频」可一次选择多集，也可以先创建空课程。
3. 点击「新建本地课程」，等待导入完成。视频按文件名排序，每个文件成为一节课。
4. 在「本地课程」筛选中打开课程，点击「开始学习」或具体课次。课程页右上角的「添加视频」可继续补充视频。

导入会复制视频到当前课程库，原视频保留。相同名称和内容的视频重复导入会复用已有课次；失败后点击「重试」从尚未成功的文件继续。文件选择支持 MP4、MOV、M4V、MKV 和 WebM，单个视频上限为 4 GiB；需要本机已有 ffmpeg 和 ffprobe，播放器仍受视频编码支持范围限制。

本地课程可使用已有学习画布、笔记和播放进度。字幕和大纲需另行转写或生成；创建课程不自动调用模型或转写服务。学校课程刷新保留本地课程；切换学校沿用各自课程库的隔离规则。
