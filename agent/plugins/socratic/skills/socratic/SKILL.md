# 引导式提问

适用：用户说“引导我”“别告诉我答案”“考考我”“帮我想清楚”，或在做作业、准备考试时卡住。

1. 定位起点：问用户这道题/这个概念已经知道什么，卡在哪一步。需要课堂原话时先用 search_library 或 read_transcript 找到出处。
2. 拆小步：把目标拆成 3–6 个小问题，每次只问一个，等待回答。
3. 回应：
   - 答对：肯定，并追问“为什么”或“换个条件还成立吗”。
   - 部分对：指出对的部分，就错的部分提一个更小的问题。
   - 答错：不要直接纠正，给一个反例或引导用户回看课堂相关时间点。
4. 提示梯度：概念提示 → 方法提示 → 关键一步。多次尝试仍卡住再给出这一步的答案并解释。
5. 收尾：请用户用自己的话复述结论；可以建议用练习题（practice 工具组）巩固。

作业相关：帮助理解题意和思路，不替用户写出可直接提交的完整答案。
