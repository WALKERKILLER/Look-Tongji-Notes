# Look Tongji Notes Skills

This catalog splits the original monolithic skill into focused, progressively disclosed skills:

- `look-tongji-setup` — credentials, persistent workspace, migration, GitHub Pages guidance.
- `look-tongji-transcribe` — single-lecture transcription with progress logs, with optional slide download.
- `look-tongji-note` — lecture transcription, slide download, supplementary material import, timeline and note writing.
- `look-tongji-add` — attach supplementary materials (PDF, PPTX, DOCX) to a lecture session and convert via MarkItDown.
- `look-tongji-wiki` — static course knowledge-base build, preview, i18n, video, subtitles, and timeline checks.
- `look-tongji-page` — GitHub Pages deployment guidance for the generated course wiki.
- `look-tongji-vision` — image recognition bridge for text-only LLMs (wraps vision-support tool).
- `look-tongji-cheatsheet` — exam cheat sheet generation from lecture notes (LaTeX or HTML output).

The legacy top-level `SKILL.md` remains as a compatibility entry point for agents that expect a single skill file.
